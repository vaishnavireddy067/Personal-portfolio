1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
This project is a complete, responsive personal portfolio website engineered 
strictly with semantic HTML5 and vanilla CSS3. No JavaScript, external 
frameworks (Bootstrap, Tailwind), package managers, or backend databases are 
utilized, fully adhering to HTML & CSS internship guidelines.

Directory Structure:
AnuguVaishnavi_HTML_CSS_Portfolio/
│
├── index.html                 (Main semantic structure and content)
├── style.css                  (Theme tokens, typography, grid, animations)
├── PROJECT_DESCRIPTION.txt    (Concise project summary for submission)
├── README.txt                 (Execution and testing instructions)
└── screenshots/
    ├── desktop.png            (Desktop viewport capture: 1280px+ or full-page)
    └── mobile.png             (Mobile viewport capture: 375px - 414px)


2. HOW TO OPEN & EDIT IN VISUAL STUDIO CODE
--------------------------------------------------------------------------------
1. Open Visual Studio Code.
2. Click "File" > "Open Folder..." (or press Ctrl + K, Ctrl + O).
3. Navigate to and select this project folder:
   "personal portfolio" (or "AnuguVaishnavi_HTML_CSS_Portfolio").
4. Both index.html and style.css will be readily accessible in the left-hand 
   Explorer sidebar.


3. HOW TO RUN THE WEBSITE IN A BROWSER
--------------------------------------------------------------------------------
Method A (Direct File Launch - Easiest):
- Open your File Explorer, navigate to the folder, and double-click `index.html`.
- Alternatively, right-click `index.html` > "Open with" > choose Google Chrome 
  or Microsoft Edge.

Method B (Via VS Code Live Server - Optional):
- If you have the "Live Server" extension installed in VS Code:
  Right-click anywhere inside `index.html` and select "Open with Live Server".


4. HOW TO TEST RESPONSIVENESS
--------------------------------------------------------------------------------
1. Open the website in Google Chrome or Microsoft Edge.
2. Press `F12` (or right-click anywhere and select "Inspect") to open DevTools.
3. Click the Device Toggle icon (or press Ctrl + Shift + M).
4. Test different viewport sizes:
   - Desktop view: Set width to 1280px or higher.
   - Tablet view: Set width to 768px - 820px (iPad size).
   - Mobile view: Choose "iPhone 14 / 12 Pro" or "Pixel 7" (375px - 414px width).
5. Verify that:
   - Navigation collapses into a clean hamburger menu on mobile.
   - Tapping the hamburger icon expands the menu smoothly without JavaScript.
   - All text, project cards, and skill chips stack vertically without 
     horizontal scrollbars.


5. HOW TO CAPTURE GENUINE SCREENSHOTS FOR SUBMISSION
--------------------------------------------------------------------------------
A. Desktop Screenshot (desktop.png):
1. Open `index.html` in your browser at full screen (1920x1080 or laptop screen).
2. Press `F12` to open Developer Tools.
3. Press `Ctrl + Shift + P` to open the Chrome/Edge Command Menu.
4. Type: "Capture full size screenshot" and press Enter.
5. The browser will automatically save a pristine, full-length image of your 
   portfolio.
6. Rename this file to `desktop.png` and move it into the `screenshots/` folder.

B. Mobile Screenshot (mobile.png):
1. In Developer Tools, toggle the Device Toolbar (`Ctrl + Shift + M`).
2. Select a device like "iPhone 14 / 12 Pro" or set the width to 390px.
3. Press `Ctrl + Shift + P` to open the Command Menu.
4. Type: "Capture full size screenshot" (or "Capture screenshot") and press Enter.
5. Rename the downloaded file to `mobile.png` and move it into the `screenshots/` 
   folder.
