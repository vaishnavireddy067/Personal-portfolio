A clean, modern, and fully responsive personal portfolio website engineered strictly with semantic **HTML5** and **vanilla CSS3**. No JavaScript, external frameworks (Bootstrap, Tailwind), package managers, or backend databases are utilized.

---

## 📌 Project Overview

This portfolio showcases academic background, technical competencies, and software engineering projects. Tailored for Software Development Engineer, AI Engineer, and Backend Developer roles, it features:
- **Design System:** Professional dark navy theme (`#070e1f`) with electric blue and cyan accent glows.
- **Hero Section:** Code-card illustration with animated glow and developer profile summary.
- **Sections:** About Me, Education & Achievements, Technical Skills, Featured Projects, Contact form, and Social links.
- **Pure CSS Navigation:** Responsive navigation bar with a pure CSS hamburger menu toggle (no JavaScript needed).
- **Accessible & Lightweight:** Built using semantic HTML5 elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).

## 🚀 How to Run Locally

### Method 1: Direct File Launch (Easiest)
1. Double-click `index.html` in your file explorer.
2. Alternatively, right-click `index.html` → **Open with** → Google Chrome, Microsoft Edge, or Firefox.

### Method 2: Visual Studio Code Live Server
1. Open this repository folder in VS Code.
2. Right-click `index.html` and select **Open with Live Server**.

---

## 📱 Testing Responsiveness

1. Open `index.html` in Google Chrome or Microsoft Edge.
2. Press `F12` (or right-click → **Inspect**) to open DevTools.
3. Toggle the Device Toolbar (`Ctrl + Shift + M`).
4. Select different viewport sizes:
   - **Desktop:** `1280px` or wider
   - **Tablet:** `768px` – `820px` (iPad size)
   - **Mobile:** `375px` – `414px` (iPhone 14 / Pixel 7)
